Network Technician — Wireless AP Configuration
CONFIGURE AP
Scenario
You are a network technician deploying a new wireless access point for a small office. The office requires a secure dual-band wireless network that meets the following requirements:
  • Network name must be CorpNet-HQ but hidden from broadcast
  • Must support devices at 5 GHz for reduced interference with maximum throughput
  • Wireless standard must be 802.11ac (Wi-Fi 5)
  • Use a non-overlapping channel — channel 36
  • Security: WPA3-Personal with AES (CCMP) encryption
  • Authentication: Pre-Shared Key (PSK)
  • Disable WPS (known vulnerability)
  • Enable Band Steering to push capable clients to 5 GHz
