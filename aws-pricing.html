Key Pricing Facts for the Exam
EC2
Pay per second (Linux) or per hour (Windows). Spot Instances save up to 90% but can be interrupted. Reserved Instances save up to 72% for 1–3 year commitments.
S3
Pay for storage + requests + data out. Inbound data is always free. Deep Archive is cheapest ($0.00099/GB). Data to CloudFront is free.
Lambda
1M requests free/month always. Pay per 1M requests + per GB-second. 400,000 GB-seconds free/month. Only pay while code runs.
RDS
Multi-AZ doubles the instance cost but gives automatic failover. Storage is separate from instance pricing. Reserved RDS saves up to 69%.
Data Transfer
Inbound is always free. First 100 GB/mo outbound free. Same-region and to CloudFront free. Cross-region and to internet charged.
Free Tier
Always Free: Lambda 1M req, DynamoDB 25GB. 12-Month Free: 750hr EC2 t2.micro, 5GB S3, 25GB RDS.
