Social Engineering
Social Engineering Phishing
Mass email impersonating a trusted source to steal credentials or deliver malware. Uses urgency, fear, or reward as psychological triggers.
DefenseEmail filtering, SPF/DKIM/DMARC, security awareness training, MFA.
Social Engineering Spear Phishing
Targeted phishing at a specific individual or organization using personalized details gathered from OSINT to increase believability.
DefenseUser training, email authentication, MFA, verify requests out-of-band.
Social Engineering Whaling
Spear phishing targeting senior executives (CEO, CFO) to authorize wire transfers or expose sensitive data. Also called CEO fraud.
DefenseExecutive security training, strict wire transfer verification procedures, MFA.
Social Engineering Vishing
Voice/phone-based social engineering. Attacker calls posing as IT, bank, or government to extract info or gain remote access.
DefenseNever provide credentials over phone; call back on official numbers; user awareness training.
Social Engineering Smishing
SMS-based phishing. Malicious links or requests sent via text message — exploits trust in SMS as a channel.
DefenseDo not click unsolicited SMS links; verify with sender directly; mobile security solutions.
Social Engineering Pretexting
Attacker fabricates a believable scenario (pretext) — e.g., posing as an auditor or IT support — to gain information or access.
DefenseIdentity verification procedures, need-to-know policy, security awareness training.
Social Engineering Tailgating/Piggybacking
Physically following an authorized person into a restricted area without using their own credentials. Exploits politeness.
DefenseMantraps, badge access, security guards, employee training to challenge unknown individuals.
Social Engineering Baiting
Leaving infected USB drives or other media in public places hoping someone plugs them in. Also applies to fake download offers.
DefenseDisable AutoRun, USB port controls, endpoint protection, user training to never plug in unknown devices.
Network Attacks
Network Attacks DoS (Denial of Service)
Single attacker floods a system with traffic or requests to exhaust resources (bandwidth, CPU, memory), making it unavailable to legitimate users.
DefenseRate limiting, firewalls, ISP-level filtering, load balancers, failover systems.
Network Attacks DDoS (Distributed DoS)
Coordinated attack using a botnet of thousands of compromised devices to overwhelm a target simultaneously. Much harder to block than single-source DoS.
DefenseDDoS scrubbing services, CDN, anycast routing, ISP upstream filtering, web application firewalls.
Network Attacks SYN Flood
TCP protocol attack that sends massive SYN packets without completing the handshake, exhausting server connection tables (half-open connections).
DefenseSYN cookies, firewall rate limiting, TCP connection timeouts, IPS signatures.
Network Attacks ARP Spoofing
Attacker sends fake ARP replies to associate their MAC with a legitimate IP, enabling on-path attacks, traffic interception, or DoS on a LAN.
DefenseDynamic ARP Inspection (DAI), static ARP entries, VLAN segmentation, port security.
Network Attacks DNS Spoofing/Poisoning
Injecting false DNS records into a resolver cache so victims are redirected to attacker-controlled servers when visiting legitimate domains.
DefenseDNSSEC, encrypted DNS (DoH/DoT), validate resolver sources, monitor DNS traffic anomalies.
Network Attacks Man-in-the-Middle (On-Path)
Attacker secretly intercepts and potentially alters communications between two parties who believe they are communicating directly.
DefenseTLS/HTTPS, certificate pinning, HSTS, MFA, VPN, network monitoring for anomalous traffic.
Network Attacks SSL Stripping
Downgrades HTTPS to HTTP during an on-path attack so traffic is sent in cleartext. Victim sees HTTP; attacker reads everything.
DefenseHSTS (HTTP Strict Transport Security), certificate transparency, HTTPS-everywhere enforcement.
Network Attacks Replay Attack
Attacker captures a valid authentication token or session and retransmits it to impersonate the legitimate user without knowing credentials.
DefenseSession tokens with timestamps, nonces (one-time values), TLS, Kerberos ticket expiry.
Network Attacks Evil Twin
Rogue Wi-Fi AP broadcasting a legitimate SSID to lure users into connecting. Enables on-path attacks, credential theft, and traffic interception.
DefenseWireless IDS/IPS, certificate-based 802.1X authentication, VPN on untrusted networks, WLAN monitoring.
Application Attacks
Application Attacks SQL Injection (SQLi)
Malicious SQL inserted into input fields manipulates the backend database — bypassing authentication, dumping data, or destroying records.
DefenseParameterized queries (prepared statements), input validation/sanitization, WAF, least-privilege DB accounts.
Application Attacks Cross-Site Scripting (XSS)
Malicious scripts injected into web pages execute in other users' browsers. Stored XSS persists in DB; Reflected XSS is in the URL; DOM-based modifies client-side code.
DefenseOutput encoding, Content Security Policy (CSP) headers, input validation, HttpOnly cookies.
Application Attacks Cross-Site Request Forgery (CSRF)
Tricks an authenticated user's browser into making unauthorized requests to a trusted site. Exploits that the site trusts the user's session cookie.
DefenseCSRF tokens (synchronizer token pattern), SameSite cookie attribute, re-authentication for sensitive actions.
Application Attacks Buffer Overflow
Writing data beyond the allocated buffer boundary overwrites adjacent memory. Can overwrite return addresses to redirect code execution to attacker's shellcode.
DefenseASLR, DEP/NX (no-execute memory), stack canaries, safe coding practices, compiler protections.
Application Attacks Directory Traversal
Using ../ sequences in file path inputs to access files outside the intended directory — reading config files, password stores, or system files.
DefenseInput validation, canonicalization, chroot jails, web server configuration to restrict document root.
Application Attacks XML External Entity (XXE)
Exploits XML parsers that process external entity references — can read local files, SSRF, or DoS by referencing infinite recursive entities.
DefenseDisable XML external entity processing in parsers, input validation, WAF, use JSON instead of XML where possible.
Application Attacks Insecure Deserialization
Attacker modifies serialized object data that is blindly deserialized, leading to remote code execution, privilege escalation, or injection attacks.
DefenseNever deserialize untrusted input; use serialization-less data formats; input validation; integrity checks on serialized objects.
Application Attacks Command Injection
Attacker injects OS commands through application input fields that are passed unsanitized to a system shell, gaining code execution on the server.
DefenseInput validation, avoid shell calls from application code, least privilege for application accounts, WAF.
Cryptographic Attacks
Cryptographic Attacks Brute Force
Systematically trying every possible password or key combination until the correct one is found. Effective against short/weak passwords offline.
DefenseLong/complex passwords, account lockout policies, MFA, salted hashes, rate limiting, CAPTCHA.
Cryptographic Attacks Dictionary Attack
Uses a precompiled list of common words, phrases, and known passwords to crack credentials — much faster than full brute force.
DefenseStrong unique passwords, password manager, MFA, bcrypt/scrypt/Argon2 for password hashing with salt.
Cryptographic Attacks Rainbow Table Attack
Uses precomputed tables mapping hash values to plaintext to instantly reverse unsalted hashes without recomputing.
DefensePassword salting (adds unique random value before hashing), use bcrypt/scrypt/Argon2 which salt automatically.
Cryptographic Attacks Password Spraying
Tries one common password (e.g., "Summer2024!") across many accounts to avoid lockout thresholds — often succeeds against weak password policies.
DefenseMFA, strong password policy, account lockout (with threshold awareness), anomaly detection for distributed failures.
Cryptographic Attacks Credential Stuffing
Uses breached username/password pairs from other sites to log into services — exploits password reuse across multiple accounts.
DefenseMFA, password managers (unique passwords per site), breach monitoring, CAPTCHA, anomaly detection.
Cryptographic Attacks Downgrade Attack
Forces a system to use a weaker encryption algorithm or protocol version (e.g., TLS 1.0, DES) so the attacker can break the weaker encryption.
DefenseDisable legacy/weak protocols and cipher suites, HSTS, TLS 1.2+ only, cipher suite ordering enforcement.
Cryptographic Attacks Collision Attack
Finding two different inputs that produce the same hash output — breaks integrity checks. MD5 and SHA-1 are vulnerable to practical collision attacks.
DefenseUse SHA-256 or stronger, replace MD5/SHA-1 in all security contexts, digital signatures with strong hash functions.
Malware
Malware Virus
Malicious code that attaches itself to legitimate files and replicates when executed. Requires user action to spread (opening an infected file).
DefenseAntivirus/EDR, email filtering, patch management, least privilege, user training.
Malware Worm
Self-replicating malware that spreads across networks without user interaction, exploiting vulnerabilities in network services or OS components.
DefensePatch management, network segmentation, IDS/IPS, disable unnecessary services, host-based firewalls.
Malware Trojan Horse
Malicious software disguised as legitimate/useful software. Does not self-replicate but creates backdoors, downloads additional malware, or steals data.
DefenseApplication whitelisting, code signing verification, EDR, download only from trusted sources, user training.
Malware Ransomware
Encrypts victim files and demands cryptocurrency payment for decryption key. Modern variants also exfiltrate data and threaten to publish it (double extortion).
DefenseImmutable offline backups (3-2-1 rule), patch management, email filtering, MFA, least privilege, network segmentation, EDR.
Malware Rootkit
Malware that hides its presence (and other malware) from the OS and security tools by operating at kernel level or even below the OS (bootkit/firmware).
DefenseSecure Boot, TPM, UEFI protections, memory integrity, offline scanning, OS reinstall when detected.
Malware Keylogger
Records keystrokes to capture passwords, credit card numbers, and sensitive data. Can be software or hardware (device plugged between keyboard and computer).
DefenseMFA (keylogged passwords alone unusable), EDR, physical inspection of workstations, encrypted keyboard input.
Malware Spyware
Silently monitors and exfiltrates user activity, browsing habits, credentials, and personal data without user knowledge.
DefenseAntimalware/EDR, browser security settings, OS updates, DLP, network monitoring for unusual outbound traffic.
Malware Botnet/RAT
Remote Access Trojan (RAT) gives attacker full control of the infected system. Botnets aggregate thousands of RAT-infected machines for DDoS, spam, or cryptomining.
DefenseEDR, network monitoring, IPS signatures, firewall egress filtering, patch management.
Insider & Physical
Insider & Physical Insider Threat
Malicious or negligent employee/contractor using legitimate access to steal data, sabotage systems, or enable external attackers.
DefenseLeast privilege, separation of duties, DLP, UEBA (User Entity Behavior Analytics), mandatory vacation, offboarding procedures.
Insider & Physical Shoulder Surfing
Physically observing someone enter a password, PIN, or sensitive information. Effective in public places, open offices, or against unlocked screens.
DefensePrivacy screens, screen lock policies, awareness training, positioning workstations away from public view.
Insider & Physical Dumpster Diving
Searching through discarded materials (physical or digital) for sensitive information — old documents, printouts, hardware containing data.
DefenseShredding policy, secure disposal of media (degaussing, physical destruction), clean desk policy.
Insider & Physical Physical Theft
Stealing devices (laptops, phones, USB drives, hard drives) containing sensitive data or credentials.
DefenseFull disk encryption (FDE), strong BIOS/boot passwords, cable locks, remote wipe capability, asset tagging, secure facilities.
